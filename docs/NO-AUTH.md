# BrowserSkills без входа в приложение

Изменение по запросу пользователя от 2026-09-09: веб-интерфейс и публичное API открывают общее рабочее пространство без логина, пароля и проверки прав пользователя.

- Удалены форма входа, кнопка выхода, endpoints `/api/auth/login` и `/api/auth/logout`, обработка истечения авторизованной сессии, проверка учётной записи и ограничитель попыток входа.
- `/api/me` теперь возвращает данные общего рабочего пространства и квоту без авторизации. `/api/csrf` обеспечивает защиту действий от запросов с посторонних сайтов; входа и пароля для него нет.
- Используется первый существующий профиль по номеру browser worker. Его ID, история запусков и постоянный Chromium-профиль сохраняются. На пустой установке рабочее пространство `local` создаётся автоматически; ручное создание учётной записи для работы приложения не требуется.
- Прежние записи других профилей и история в БД не удаляются и не объединяются. Служебный CLI сохраняется для конкретных текущих потребителей `ops/windows/Manage-User.ps1` и `ops/windows/Publish-RemoteUi.ps1`; его пароли не дают доступа к веб-интерфейсу и нигде в нём не проверяются. Условие удаления CLI и его PasswordEncoder: перевод этих скриптов и проверок восстановления на автоматическое общее пространство без вызовов `--create-user`/`--disable-user`. Это совместимость установщика, а не альтернативный путь входа.
- noVNC использует обычную анонимную HTTP-сессию только для координации ручного управления. Это позволяет предотвращать одновременные нажатия из двух браузеров и отзывать управление перед автоматическим запуском. Авторизованной сессии приложения больше нет.
- Вход и двухфакторка самого Яндекса сохраняются. Служебные соединения с PostgreSQL и browser workers не меняются этим изменением.

Изменения подготовлены локально в боковой беседе. Развёртывание `.107` этой беседой не изменялось. Основной процесс разработки и его изменения сохранены.

## Проверка локального изменения

- 26 тестов Web прошли, покрытие строк 97.6%; TypeScript и проверка diff прошли.
- Три сценария интерфейса в Chromium завершились успешно. Процесс запуска тестов завис на завершении web server и был остановлен после окончания всех трёх сценариев; успешный exit code всего launcher не заявляется.
- В изолированной копии API прошли 3 unit-теста (`RequestBodyLimitTest`, `ManualLeasesTest`, `VncPendingTest`) и 18 интеграционных тестов (`ServerIT`, `StoreIT`) с настоящей PostgreSQL. Проверены отсутствие требования входа, общее пространство для нового HTTP-клиента, удалённые auth endpoints, noVNC без principal и стабильное создание первого профиля.
- Полный `mvn verify` в этой копии остановился на изменяемом основной задачей тесте `PrivateClientsTest.answerGrammarSeparatesRefusalAndConstrainsEachObservedFieldType`: вложенность JSON 13 превышала лимит тестового parser 12. Эта боковая беседа не меняла модель или соответствующий тест и не объявляет общий Maven-прогон успешным.
