# Проверка автономного Янг — 2026-09-09

Итоговый пользовательский выбор: одно общее пространство без входа в BrowserSkills. Вход и двухфакторка самого Яндекса сохраняются. Предыдущие результаты старого контракта находятся в [историческом отчёте](verification-before-autonomy.md).

## Обновление серверного браузера

Добавлены полноэкранный режим (либо разворачивание на всё окно при запрете Fullscreen API), масштаб 100% с прокруткой и панель обмена текстом. Ctrl+V работает с компьютера в Янг, включая русскую раскладку; текст после Ctrl+C в Янг копируется на компьютер явной кнопкой. Кириллица, emoji и переносы строк сохраняются. Интерфейс ограничивает текст 64 КиБ, TigerVNC допускает 128 КиБ транспортных данных с учётом оформления ExtendedClipboard. Clipboard не сохраняется в БД и очищается из интерфейса при отключении.

Вместо Xvfb/x11vnc используется TigerVNC. RFB остаётся доступен только на loopback за существующим мостом управления; опубликованного VNC-порта нет. Во время MANUAL сканирование каталога не открывает вкладки. Начатый скан завершается до передачи управления. Также устранено промежуточное подключение WebSocket при повторном открытии браузера.

Каталог и DOM двух аудиопроектов исследованы в авторизованном браузере Codex; сведения сохранены в [YANG-MIGRATION.md](YANG-MIGRATION.md). Наблюдались радиовкладки, ID проекта через инструкцию до резервирования, цена за целый набор, aria-label материалов, отдельный каталог активных наборов и таймер `.task-info__values-time` со значением `0:00`. Реальные ответы не отправлялись. Внешний HTML голосовой инструкции ранее вернул `ERR_BLOCKED_BY_CLIENT`; его полное содержимое не подтверждено.

Четыре настоящих запроса к Qwen на `.107` после усиления схемы дали корректный формат во всех четырёх случаях, но только один полностью правильный составной набор: text — неверно, image — неверно, speech — верно, sound/prosody — неверно. Время: 1.77 / 9.35 / 28.62 / 25.25 секунды. Это короткая синтетическая проверка формата, не оценка категорий и не весь рабочий процесс. Отчёт: `runtime/model-contract-smoke-20260909T082002Z.json`.

Старый синтетический корпус давал text 88%, image 80%, speech 100%, sound/prosody 28%. Эти результаты также не являются допуском. **Ни одна категория не допущена к автоматической отправке.** Рабочий файл допуска пуст. Нужны независимые эталонные ответы минимум для 25 целых наборов на категорию и минимум 90% полностью правильных наборов; отказы считаются нерешёнными.

Остаются отдельными проверками: реальный вход с двухфакторкой в серверном Chromium, качество на рабочих заданиях и перезагрузка самого Windows-хоста. Вход браузера Codex не переносится в серверный профиль. В обычном Chromium и пользовательском Chrome noVNC на `.107` проверен. В Chrome после перезапуска открыто действующее ручное подключение для входа в Янг. Во встроенном браузере Codex соединение закрывалось; его совместимость с noVNC не подтверждена.
